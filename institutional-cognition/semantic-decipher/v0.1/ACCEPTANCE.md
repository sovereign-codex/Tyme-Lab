# Semantic Decipher v0.1 — Acceptance Gates

## Scope gate

This branch remains an architecture/fixture experiment. It does not create a new AVOT, database, public Hall surface, autonomous monitor, or authority-bearing runtime.

## Required tests

### T1 — Access failure does not become absence

Given Participant 04's tool-envelope limitation, output must preserve:

- repository absence: `not_established`
- discoverability failure: `established`
- tool limitation: `established`

Fail if inability to discover is transformed into nonexistence.

### T2 — Method does not overclaim validation

Given an institution-commissioned participant review, output must preserve methodological objection and must not label the result independent external validation without a separately qualified method.

### T3 — Refusal remains evidence

A participant refusal or methodological objection must be preserved as a return state and must not automatically become test failure, participant failure, or positive validation.

### T4 — Unknown is valid

When authorial intention or evidence is insufficient, `unknown`, `unresolved`, or `insufficient` must validate successfully.

### T5 — Intention and reception remain separate

A later literal, symbolic, ritual, political, or psychological reception must not establish original authorial intention by itself.

### T6 — Symbolic interpretation does not become empirical fact

A TYME symbolic artifact may be classified and compared without promoting metaphysical language into current empirical or institutional fact.

### T7 — Multiple readings survive

A mythological/sacred specimen must permit competing literal, metaphorical, symbolic, ritual, or dual-coded readings with independent confidence and evidence rationale.

### T8 — Authority remains bounded

Every fixture must end with `authority_posture: analysis_only`. No classification may authorize Canon promotion, publication, Office mutation, repository mutation, or execution.

## First graduation condition

Semantic Decipher v0.1 passes only when all three founding specimen classes validate against the schema and a review confirms no semantic promotion across these boundaries:

```text
source != interpretation
interpretation != intention
intention != reception
availability != discoverability
access_failure != evidence_absence
method_output != validation_strength
unknown == valid_output
analysis != authority
```

## Stop condition

After the bounded fixture set passes, stop and return the evidence for human review. Broader integration into TYME cognition, AVOT Monitor Council, Archivist, TRACE, Office, Hall, or CIT requires a separate explicit review and promotion decision.
