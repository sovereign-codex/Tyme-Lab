# CIT Adaptive Learning Loop v0.1

Status: architecture candidate  
Authority: non-authorizing  
Public deployment: not authorized

## Root decision

The primitive is the learning loop, not the course.

The Steward finds the nearest viable connecting point between participant and subject, adapts representation and scaffolding without silently changing authority, invites bounded action, observes evidence, and returns only what the participant chooses or what a declared mission requires.

The loop must scale from first-symbol learning to expert systems work without assigning a permanent global learner level.

## Core loop

```text
ENCOUNTER
  -> ORIENT
  -> CONNECT
  -> EXPRESS
  -> ACT
  -> OBSERVE
  -> ADAPT
  -> REFLECT
  -> EVIDENCE
  -> CONTRIBUTE_OR_PRIVATE_EXIT
  -> REVIEW_OR_INHERIT_WHEN_ACCEPTED
  -> REORIENT
```

The loop is recursive. Evidence may send the encounter back to ORIENT, CONNECT, EXPRESS, or ACT.

## Three-layer architecture

### A. Interaction Loop

Participant-facing responsibilities:

- receive intent without requiring enrollment;
- disclose the active assistance relationship;
- find the nearest viable connecting point;
- render one semantic state through usable modalities;
- invite bounded action;
- change scaffolding without changing evidence authority;
- allow pause, refusal, renderer change, or private exit without penalty.

### B. Cognitive State Model

The runtime may keep bounded, revisable observations about:

- current concept or mission;
- demonstrated evidence;
- unresolved prerequisites;
- current representation;
- current scaffolding;
- participant-declared modality or accessibility preference;
- uncertainty;
- next candidate connecting point.

It must not silently become a global intelligence score, permanent learner level, worth score, obedience score, dependence score, reputation score, employability score, irreversible developmental history, or institutional authority.

### C. Inheritance Protocol

Default behavior: no automatic inheritance.

Possible governed outcomes include:

```text
PRIVATE_OR_DISPOSABLE_ENCOUNTER
CONTEXTUAL_LEARNING_EVIDENCE
CCE_CDM_DEVELOPMENTAL_SPECIMEN
CONTRIBUTION_CANDIDATE
ACCEPTED_CONTRIBUTION_TRAIL
HALL_EVENT
PROMOTED_KNOWLEDGE
```

Each transition uses the existing consent, provenance, review, and governance boundary appropriate to that object.

## Connecting-point rule

The Steward does not ask "what level is this person?" as its primary model. It asks "what is the nearest point from which this concept can become mutually intelligible?"

A connecting point may be a familiar object, word, sound, analogy, visible pattern, prior demonstrated skill, code fragment, trace, physical action, formal model, or unresolved contradiction.

Connecting points are concept-local, temporary, and revisable.

## Participant-facing verbs

```text
TALK  -> converse, listen, pronounce, question
SEE   -> read, inspect, visualize, compare
TRY   -> predict, manipulate, retrieve, rehearse, test
MAKE  -> code, build, measure, experiment, repair, compose
SHARE -> offer a bounded Contribution Candidate
```

These are affordances, not progression ranks.

## Assistance relationship

The runtime preserves three distinct relationships:

- LEARN: increase participant-independent capability. The Steward scaffolds, tests reconstruction, and withdraws support when appropriate.
- DELEGATE: complete a task through bounded assistance without claiming participant learning.
- CO_CREATE: preserve consequential participant and machine contributions distinctly.

Renderer changes, hints, successful answers, or completed tasks may not silently change the assistance relationship.

## Evidence grammar

Useful evidence may include recognition, recall, prediction, reconstruction, explanation, transfer, build, diagnosis, repair, critique, teaching return, or explicit intentional delegation.

Immediate task success alone is insufficient to establish independent capability.

## Adaptation dimensions

The Steward may adapt:

1. abstraction;
2. vocabulary;
3. scaffolding;
4. representation;
5. tempo;
6. verification demand.

Adaptation must remain concept-local and contestable. It must not create rank or authority.

## Reciprocal intelligence boundary

Human or machine participants may both learn from bounded returned evidence, but the Hall preserves the external lineage required to reconstruct and contest what changed.

Machine contextual learning does not become institutional authority by itself.

## Foyer to inheritance seam

```text
FOYER
  -> ASK / SEEK / KNOWLEDGE
  -> STEWARD ENCOUNTER
  -> ADAPTIVE LEARNING / PARTICIPATION LOOP
  -> LAB OR REAL-WORLD ACTION WHEN NEEDED
  -> REFLECTION + EVIDENCE
  -> OPTIONAL SHARE
  -> CONTRIBUTION CANDIDATE
  -> OFFICE INTAKE / REVIEW
  -> CONTRIBUTION TRAIL / HALL INHERITANCE WHEN ACCEPTED
```

The Foyer remains an orientation surface, not the learning runtime itself.

## Capability boundary

Permitted direction:

```text
I_AM
  -> DECLARED_INTENT_AND_CONTEXT
  -> ADAPTIVE_ENCOUNTER
  -> EVIDENCE
  -> REVIEW_OR_ATTESTATION_WHERE_REQUIRED
  -> CAPABILITY_GRAPH_UPDATE
  -> ADAPTIVE_INTERFACE_OR_ALLOCATION_CONSEQUENCES
```

Forbidden shortcut:

```text
UNREVIEWED_AI_INFERENCE -> CAPABILITY_ENTITLEMENT
```

No consequential capability, credential, resource allocation, or stewardship authority may arise solely from unreviewed model inference.

## Child and accessibility boundary

Multimodality is an accessibility primitive.

For child-facing or developmentally sensitive rehearsal:

- synthetic data only in v0.1 validation;
- retention minimized by default;
- guardian or supervisor posture preserved where required;
- no advertising or manipulative engagement mechanics;
- no hidden developmental, dependence, obedience, worth, or risk score;
- no public immutable developmental history;
- no autonomous credential, admissions, employment, or consequential access decision;
- eligible developmental projections remain inspectable and contestable.

## Minimum durable return responsibilities

A governed return may preserve only what is required to reconstruct its declared consequence, including:

```text
encounter_id
participant_control_posture
participant_intent
assistance_mode
concept_or_mission
semantic_state_ref
connecting_point
representation_state
scaffolding_state
participant_action
evidence_refs
participant_reflection
uncertainty
capability_effect_candidate
contribution_candidate_ref
consent_disclosure_posture
review_state
next_valid_transition
```

These are semantic responsibilities, not authorization for a new universal schema.

## Acceptance gate

A bounded rehearsal passes only if:

1. one semantic state survives renderer changes;
2. different connecting points can be used without assigning global rank;
3. Learn / Delegate / Co-create remains explicit;
4. task completion is not confused with independent capability;
5. scaffolding can decrease without withdrawing needed accessibility support;
6. private exit remains available without penalty;
7. SHARE creates only a Contribution Candidate;
8. ordinary micro-interactions do not automatically become Hall Events;
9. returned evidence remains contestable and provenance-rich;
10. machine contextual learning does not become institutional authority;
11. no consequential capability grant is issued from unreviewed inference;
12. a later participant can reconstruct an accepted return without private Steward cognition.

## Prohibited outcomes

This contract does not authorize:

- learner ranking;
- credentials;
- reputation or dependence scoring;
- production child records;
- automated admissions or employment judgments;
- engagement feeds optimized for captured attention;
- automatic Hall Event emission for ordinary interactions;
- autonomous contribution acceptance;
- public autonomous Steward deployment;
- Canon promotion;
- mutation of existing constitutional schemas.

## Memory compression

Encounter the participant where mutual intelligibility is possible; preserve the assistance relationship; adapt representation rather than rank the person; ask for action that can produce evidence; let learning remain private unless the participant or mission returns it; and allow only reviewed, provenance-rich consequences to become inheritance.
