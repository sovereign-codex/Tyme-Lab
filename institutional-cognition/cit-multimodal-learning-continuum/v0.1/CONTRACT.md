# CIT Multimodal Learning Continuum v0.1

Status: architecture / interaction candidate  
Authority: non-authorizing  
Public deployment: not authorized

## Root decision

One semantic learning state should be able to render through many modalities without becoming many separate conversations.

The Steward finds the nearest viable connecting point between participant and subject, then renders the same underlying relationship through the smallest useful combination of speech, text, visual representation, manipulation, code, experiment, or project work.

The participant is not assigned a permanent level. Representation adapts to the current concept, intent, evidence, accessibility need, and demonstrated independence.

## Inherited constitutional spine

This contract specializes, but does not replace:

- TYME Hall Learning Inheritance Runtime v0.1;
- TYME Stewarding Contract v0.1;
- TYME Learning–Capability Covenant v0.1;
- CCE/CDM Hall Integration Packet v0.1;
- Contribution Trail v3;
- Hall Event Envelope v0.1.

The governing distinctions remain:

- Stewarding governs how assistance enters an encounter without acquiring authority.
- Learn / Delegate / Co-create governs the participant's declared relationship to cognitive assistance.
- This contract governs representation and interaction affordances.
- CCE/CDM may carry consent-aware developmental evidence when needed.
- A Contribution Candidate is only an offered return until institutional intake accepts it.
- The Hall Event Envelope records accepted consequential events, not every micro-interaction.

## Five participant verbs

```text
TALK  -> converse, listen, pronounce, question
SEE   -> read, inspect, visualize, compare
TRY   -> manipulate, predict, answer, rehearse, test
MAKE  -> code, build, experiment, repair, compose
SHARE -> offer a Contribution Candidate for review and possible inheritance
```

These are affordances, not ranks. A participant may move among them in either direction.

## Multimodal synchronization invariant

Every renderer in one encounter must point to the same semantic state unless an explicit state transition is recorded.

A modality change must not silently change:

- the claim under discussion;
- evidence state;
- participant intent;
- assistance mode;
- encounter mode;
- authority posture;
- review state.

Audio and display are synchronized projections, not independent conversational truths.

## Steward representational gradient

The Steward may adapt six dimensions continuously:

1. Abstraction — concrete object -> analogy -> concept -> formal model.
2. Vocabulary — first words -> ordinary language -> disciplinary terminology.
3. Scaffolding — imitation -> hints -> collaborative solving -> independent execution.
4. Representation — speech, text, image, diagram, code, simulation, physical action.
5. Tempo — repetition and turn-taking -> dense high-bandwidth exchange.
6. Verification — recognition -> demonstration -> explanation -> transfer -> critique / teaching.

Adaptation is concept-local and revisable. Difficulty with one concept must not become a global inference about intelligence, worth, age-equivalent ability, reputation, or authority.

## Connecting-point boundary

A participant-facing system should not rely on a permanent global `learner_level` as its primary model. Bounded observations may describe the current concept, demonstrated evidence, current abstraction, scaffolding state, accessibility preference, and next connecting point.

Participant interpretation and inferred capability effect must remain contestable.

No new universal learner schema is authorized by this contract.

## Adaptive learning loop

```text
ENCOUNTER
  -> ORIENT
  -> FIND CONNECTING POINT
  -> EXPRESS
  -> INVITE ACTION
  -> OBSERVE
  -> ADAPT / REDUCE OR CHANGE SCAFFOLDING
  -> REFLECT
  -> RETURN EVIDENCE OR EXIT PRIVATELY
```

A healthy loop may direct a participant away from the screen to speak, observe, move, build, measure, repair, or gather evidence in the world.

## Three-distance validation

The first deterministic rehearsal spans three synthetic participant contexts while preserving one Steward contract:

### A — Early learner specimen

Connect a spoken phoneme to a visible letter and an observable example. Preserve synthetic-only data, bounded retention, guardian / supervisor posture where required, and no developmental rank.

### B — Developing builder specimen

Understand and alter a simple repetition loop through audible explanation, visual manipulation, pseudocode or code, and independent explanation.

### C — Expert practitioner specimen

Diagnose a duplicate distributed-worker execution through traces, code, competing hypotheses, a bounded repair, and provenance-rich rationale.

The representational density may change. The constitutional relationship must not.

## Contribution Candidate boundary

`SHARE` means offer, not accept.

```text
PARTICIPANT ENCOUNTER
  -> SHARE (optional)
  -> CONTRIBUTION CANDIDATE
  -> INTAKE / REVIEW
       -> decline / private / defer
       -> accept
            -> CONTRIBUTION TRAIL
            -> possible Hall inheritance
```

A Contribution Candidate does not automatically become institutional memory, promoted knowledge, a capability claim, or a Hall Event.

## Hall Event boundary

Renderer changes, hints, retries, and ordinary conversation turns remain subordinate encounter evidence unless a declared mission or governance purpose requires durable admission.

A Hall Event is emitted only after a consequential state or return is normalized and accepted into institutional memory.

Candidate multimodal fields such as `active_representation`, `representation_transition`, and `scaffolding_state` belong in referenced payload or evidence objects when needed; they do not justify top-level mutation of Hall Event Envelope v0.1.

## Accessibility and child-participation boundary

Multimodality is an accessibility primitive. A participant may prefer or disable audio, text, visual, interactive, or later embodied renderers without losing encounter continuity.

For child-facing rehearsal:

- use synthetic identities and evidence only;
- preserve guardian / supervisor posture where required;
- minimize retention;
- prohibit advertising or manipulative engagement mechanics;
- prohibit hidden behavior, intelligence, worth, risk, obedience, dependence, or reputation scores;
- prohibit public immutable developmental history;
- prohibit autonomous credential or consequential capability issuance;
- preserve inspect, contest, withhold, and eligible revocation paths.

CCE/CDM remains the specialist developmental carrier. This contract does not create a second child-record system.

## Acceptance criteria

A v0.1 rehearsal passes only if:

1. the same semantic state survives voice <-> text <-> visual / interactive transitions;
2. the same Steward contract spans all three synthetic cognitive-distance specimens without global ranking;
3. Learn / Delegate / Co-create remains explicit and is not silently changed by renderer transitions;
4. immediate task success is not automatically emitted as increased participant capability;
5. `SHARE` yields only a Contribution Candidate before intake;
6. multimodal micro-interactions do not automatically emit Hall Events;
7. child-facing evidence remains synthetic during this validation cycle;
8. participant interpretation and inferred capability effect remain contestable;
9. modality changes do not increase evidence authority;
10. a later participant can reconstruct the returned object without relying on private Steward cognition.

## Prohibited outcomes

This contract does not authorize:

- learner ranking;
- credentials;
- reputation or dependence scores;
- automated admissions or employment judgments;
- production child records;
- engagement feeds optimized for captured attention;
- broad curriculum generation as institutional authority;
- public autonomous Steward deployment;
- mutation of CCE/CDM or Hall Event Envelope schemas;
- merge or Canon promotion.

## Memory compression

The Steward does not teach a demographic. It finds the nearest viable point of mutual intelligibility, renders the relationship through modalities the participant can use, withdraws scaffolding when learning is intended, and preserves what became without turning assistance into authority or development into rank.
