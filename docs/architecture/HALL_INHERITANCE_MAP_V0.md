## Cross-linking rule

Do not cross-link repositories merely to make the lattice look connected.

Create a live relation only when at least one is true:

1. runtime dependency;
2. evidence/provenance dependency;
3. governance constraint dependency;
4. publication/inheritance relation;
5. explicit Work relationship;
6. validated supersession/lineage relation.

Every cross-link should answer **why this relation matters institutionally**.
