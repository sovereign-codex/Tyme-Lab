# TYME Cognition Pilot 01 — Living Branch Orientation

## Objective
Prove that TYME can orient itself to one living branch using durable institutional evidence and return six answers: origin, present state, stewardship, evidence, authority boundary, and next valid transition.

## Pilot lineage
HB-04B / `activation-hb04-frontier-containment-001` is the first lineage under test because the current heartbeat work already separates activation consumption, process start, bounded authority, evidence return, and replay resistance.

## Non-goals
- full repository inventory
- historical archaeology
- new autonomous authority
- public Hall redesign
- distributed blockchain or token infrastructure

## Living-tree interpretation
The pilot normalizes existing evidence into these states:

`seed -> bud -> active_branch -> field_validation -> fruit | graft | dormant | pruned`

The state model is interpretive. It does not replace Work, Participation, or Authority state machines already present in Tyme-Lab.

## Six-question orientation contract
TYME must answer:

1. Where did this come from?
2. What is happening now?
3. Who is tending it?
4. What proves the current state?
5. Where does authority stop?
6. What may happen next?

Each answer must distinguish durable knowledge from inference or unresolved state.

## Role distinctions
- **Participant**: is present within the governed matter and may observe, orient, reason, or act within granted bounds.
- **Contributor**: returns evidence or interpretation that becomes part of institutional inheritance after the applicable review boundary.
- **Steward**: holds matter-scoped responsibility for tending continuity, health, or next valid gates.

Participation does not imply contribution. Contribution does not imply stewardship. None of these roles create global rank.

## Schemas
- `schemas/living-branch-orientation.v0.schema.json`
- `schemas/coherence-event.v0.schema.json`

A coherence event is append-oriented provenance. It does not grant authority by itself.

## First implementation pass
A read-only adapter should consume existing HB-04B durable evidence and produce a `living-branch-orientation.v0` document. Runtime behavior must not change during this pass.

## Acceptance threshold
TYME can inspect one current HB-04B lineage and reliably state where it came from, what it is becoming, who is tending it, what evidence establishes the state, where authority stops, and what transition is valid next.
