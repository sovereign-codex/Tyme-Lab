# TYME Cognition Pilot 03B — Live Read-Only Observation

## Inheritance

Exact base: `5969f02ca6381bb11a93fe08b1719126c44dce16`

Pilot 03B inherits the frozen Pilot 02 attention contract and Pilot 03 deterministic discovery/provenance chain without weakening or redesigning them.

## Mission

Change only the evidence-acquisition boundary.

Pilot 03B asks:

> Can TYME acquire a bounded live GitHub repository snapshot read-only, bind the observations to immutable Git provenance, transform them into the frozen Pilot 03 evidence contract, run the inherited cognition chain, emit one non-authorizing orientation, and stop?

## Frozen cognition chain

`Git identity -> verified bytes -> verified semantics -> candidate boundary -> eligibility -> comparative evidence -> NOW/unresolved -> non-authorizing orientation`

Pilot 03B MUST reuse this chain rather than introduce a second ranking, grouping, eligibility, or authority model.

## Allowed live observation surface

The first live adapter may read only GitHub evidence required to construct a bounded repository snapshot, including:

- repository/default-branch identity and exact commit SHA;
- repository files at explicit immutable refs;
- open pull-request metadata and exact head/base SHAs;
- review findings/comments required as evidence;
- CI/workflow status associated with observed commits;
- branch/ref metadata required to connect those artifacts.

Every live observation admitted to cognition MUST retain an immutable evidence coordinate sufficient for later replay or verification.

## Snapshot-before-cognition rule

Live state MUST NOT be streamed directly into priority logic.

The adapter must first freeze a bounded observation packet with an exact observation time and immutable Git coordinates. The inherited Pilot 03 adapter then reasons over that frozen packet.

`read live -> freeze snapshot -> verify provenance -> inherited discover/orient -> validate -> stop`

## Explicitly prohibited

Pilot 03B MUST NOT:

- create, update, merge, close, reopen, or delete pull requests;
- create, update, delete, or force-move branches/tags/refs;
- commit or modify repository content as part of observation;
- trigger, rerun, cancel, or approve workflows to obtain evidence;
- dispatch Fabricator, Archivist, TRACE, Office, or another participant;
- create or mutate Notion records;
- publish, promote, canonize, commission, or execute discovered work;
- broaden to other repositories or institutional systems during the first live test;
- change Pilot 03 comparison semantics merely because live evidence is inconvenient or incomplete.

The development commits that implement and test Pilot 03B on this branch are outside the runtime observation authority and remain human-governed repository changes.

## Fail-closed laws

Pilot 03B must stop unresolved when:

- an observed artifact cannot be rebound to an immutable Git identity;
- mutable and immutable observations disagree without a defensible snapshot boundary;
- required evidence disappears between discovery and freeze;
- the live field cannot be represented by the frozen Pilot 03 contract without inventing semantics;
- comparative evidence cannot justify one unique NOW surface.

Missing live evidence is not permission to infer authority or priority.

## First experiment

Scope the first live observation to `sovereign-codex/Tyme-Lab` only.

The first successful run must:

1. identify the exact observed repository head;
2. discover live candidate artifacts without a human-authored candidate list;
3. freeze those observations into a replayable snapshot;
4. provenance-bind every semantic root admitted to cognition;
5. invoke the inherited Pilot 03 discovery/orientation path unchanged;
6. emit one validator-clean non-authorizing orientation or an explicit unresolved result;
7. make zero institutional mutations during runtime observation.

## Success criterion

The same frozen live snapshot must replay to the same cognition result after the live repository has moved on.

That distinction is essential: Pilot 03B tests live perception, while Pilot 03 remains the deterministic reasoning substrate.

## Promotion boundary

Pilot 03B is not authorization for recommendation execution, commissioning, branch mutation, Office delegation, Fabricator dispatch, or autonomous cleanup.

Any future capability that acts on an orientation requires a separate pilot and separate authority contract.
