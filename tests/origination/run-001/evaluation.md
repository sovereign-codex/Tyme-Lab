## Important emergent observation

The strongest evidence from Run 001 is not yet that any M3 label is wrong.

The strongest evidence is that the origination mechanism caused an external intelligence to:

1. inspect rather than merely accept institutional claims;
2. generate a falsifiable institutional question;
3. discover and retract its own initial factual error;
4. preserve uncertainty and counterarguments;
5. narrow the proposition before submitting it;
6. request bounded reconciliation rather than self-authorizing a correction.

That behavior is directly relevant to the origination/contribution hypothesis being tested.
